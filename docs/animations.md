Animations

Animation scales control how fast windows/transitions/animators play.
`1.0` = stock, `0.5` = snappy (recommended), `0` = off (fastest, can look janky).

Commands used

```sh
settings put global window_animation_scale 0.5
settings put global transition_animation_scale 0.5
settings put global animator_duration_scale 0.5
```

Tips
- 0.5x feels faster without looking broken — best for daily use
- Full `0` is great on low-end phones
- Some launchers also have their own animation settings
